# 연구의 길 · 학생용 연구설계 작업실 0.9.0

관심사를 설명하면 필요한 질문, 설계 대안, 주장할 수 있는 범위와 다음 연구 작업을 비교하는 로컬 프로그램입니다. 사회과학 전반의 393개 방법 이름을 탐색하며, 설명·출처·추천·실행의 검토 상태를 구분합니다. 전체 방법의 검증이 끝난 제품은 아닙니다.

## Windows에서 시작하기

1. [Releases](https://github.com/jinmin75/research-design-workbench/releases)에서 `research-workbench-student-0.9.0.zip`을 받습니다.
2. 압축을 개인 PC의 일반 폴더에 풉니다. ZIP 안에서 바로 실행하지 마세요.
3. [Node.js](https://nodejs.org/) 22 이상을 설치합니다. 별도의 npm 패키지 설치는 필요 없습니다.
4. `Start.cmd`를 실행합니다. 브라우저에 `http://127.0.0.1:4317/` 작업실이 열립니다.

연구 안내·계산·저장·내보내기는 외부 AI 없이도 사용할 수 있습니다. API 키나 AI 구독을 먼저 준비할 필요는 없습니다. Windows 실행 스크립트를 제공하며, 다른 운영체제와 학생별 PC 설치는 별도 검증이 필요합니다.

## AI 연결은 필요한 제공자만 준비하기

| 제공자 | 준비 | 앱에서 할 작업 |
| --- | --- | --- |
| ChatGPT | [공식 Codex CLI](https://developers.openai.com/codex/quickstart) 설치와 사용 가능한 본인 구독 | GPT / Codex 로그인 시작 → 공식 창에서 로그인 → 상태 확인 |
| Claude | [공식 Claude Code](https://code.claude.com/docs/en/setup) 설치와 사용 가능한 본인 구독 | Claude 로그인 시작 → 공식 창에서 로그인 → 상태 확인 |
| Gemini | [Google AI Studio API 키](https://aistudio.google.com/app/api-keys) | Gemini API 설정에 키 입력 → 이용 조건 확인 → 이 실행 동안 사용 |

Gemini CLI는 필요 없습니다. Gemini API는 Gemini 구독과 별도이며 프로젝트별 사용량·요금·데이터 처리 조건이 적용됩니다. [Gemini API 안내](GEMINI-API.md)를 먼저 확인하세요. ChatGPT·Claude 역시 해당 계정의 도구 사용 권한과 한도가 적용됩니다. 무제한 사용이나 추가 비용 없음을 보장하지 않습니다.

전체 앱을 자기 PC에서 사용하는 경우 별도의 `Start-Connector.cmd`를 실행할 필요는 없습니다. 이 연결기는 강사가 따로 운영하는 공유 웹앱에 접속할 때 사용하는 부가 기능입니다. [개인 연결기 안내](CONNECTOR-README.md)

## 연구 진행하기

1. 궁금한 현상과 현장 상황을 자유롭게 설명합니다. 질문·자료가 정해지지 않아도 시작할 수 있습니다.
2. 쉬운 추가 질문에 답하고, 모르면 미정으로 남깁니다.
3. 설계 대안과 부족한 정보, 경쟁 설명, 주장 범위와 수정 경로를 비교합니다.
4. AI를 사용할 때는 보낼 맥락을 미리 보고 동의합니다. 응답은 검토할 초안이며 조건을 자동 확정하지 않습니다.
5. 제안을 선택하고 변경 전후를 확인한 뒤 반영합니다. 판단 기록을 남기고 저장합니다.
6. 계산·그림과 내보내기에는 자료·단위·분모·출처·판본을 연결합니다. 설계나 자료를 바꾸면 기존 결과를 다시 검토합니다.

AI 설명·자동 검사·코드 실행은 연구 적합성이나 인과 주장 검증을 대신하지 않습니다. 질적·혼합연구 기록과 해석은 연구자가 검토합니다. 현재 검사와 미실시는 [RELEASE-VERIFICATION.md](RELEASE-VERIFICATION.md)에 구분했습니다.

## 저장·종료·업데이트

프로젝트는 이 폴더의 `projects/`에 판본별로 저장됩니다. 프로그램이 GitHub로 자동 전송하지 않습니다. AI 요청에 동의한 맥락은 해당 제공자에게 전송됩니다. PC의 동기화·백업 설정은 별도입니다.

- 브라우저를 닫아도 서버는 실행 중일 수 있습니다. 완전히 종료하려면 `Stop.cmd`를 실행합니다.
- Gemini 키는 실행 중인 서버 메모리에만 있습니다. 키 삭제 버튼을 누르거나 서버를 종료하면 다시 입력해야 합니다. 프로젝트·JSON 백업·배포 ZIP에 키를 저장하지 않습니다.
- 앱의 JSON 백업을 개인 폴더에 보관하세요. 백업에는 연구 내용이 포함되므로 공개 저장소에 올리지 마세요.
- 업데이트 ZIP은 새 폴더에 풉니다. 이전 앱에서 JSON 백업 → 이전 앱 종료 → 새 앱 실행 → 백업 가져오기 순서로 옮깁니다. 기존 `projects/` 폴더를 덮어쓰지 마세요.

포트 사용 중 오류가 나면 기존 작업실을 종료한 뒤 실행하세요. Node.js 설치 후 인식되지 않으면 새 터미널이나 탐색기에서 다시 실행합니다. 공식 도구 로그인과 Gemini API 오류는 화면에 원인과 다음 조치를 표시하며 다른 모델·과금 경로로 자동 전환하지 않습니다.

이 배포본은 Node.js나 공식 AI 도구를 포함한 설치 프로그램이 아닙니다. 업데이트와 제공자 변경에 따른 유지보수가 필요합니다. 프로그램 코드 공개와 별개로 외부 출처·AI 서비스에는 각 제공자의 이용 조건이 적용됩니다.
